# Markdown 语法支持

设置里的文档都用内置的 Markdown 解释器渲染。这一页列出它**支持的写法**，
你要自己写一份说明文档时，照这些语法写就能正常显示。

解释器是启动器自带的，**不联网、不加载网页**，所以打开很快，也不会有网页那类安全风险。

---

## 块级语法

### 标题

用 `#` 到 `######`，一级最大：

```
# 一级标题
## 二级标题
### 三级标题
```

### 段落

连续的行会合并成一段；中间空一行就是新段落。

### 列表

支持**无序**和**有序**，并且**可以按缩进嵌套**：

```
- 一级
  - 二级
    - 三级
1. 第一步
2. 第二步
```

嵌套时标记会跟着变：无序是 `●` → `○` → `■`，有序是 `1.` → `a.` → `i.`。

> 缩进更多但**不是新列表项**的行，会被当成上一项的续行（懒延续），不会另起一段。

### 代码块

用三个反引号（或三个波浪号）围起来，**可以带语言标识**，标识本身不会显示出来：

````
```csharp
var x = 1;
```
````

收尾围栏必须**不短于**起始围栏，所以代码内容里出现 ``` 也不会误判结束。

### 表格

```
| 列一 | 列二 |
|---|---|
| a | b |
```

分隔行是必需的——只有下一行确实是分隔行时才会当成表格。
**所以在正文里随手打个竖杠 `|` 不会把排版搞乱。**

### 引用

用 `>` 开头，会显示**左侧强调色竖条 + 淡背景**。多行会保留换行。

### 分隔线

一行 `---`、`***` 或 `___` 即可。

## 行内语法

| 写法 | 效果 |
|---|---|
| `` `代码` `` | 等宽字体 |
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `***粗斜体***` | 粗体套斜体 |
| `[文字](地址)` | 可点击链接 |

### 嵌套是支持的

`**粗体包含*斜体***` 会正确渲染成 **粗体里套斜体**。

这点没法用一条正则做到（正则表达不了嵌套），所以解释器是**手写扫描器**，
遇到标记就递归解析里面的内容。

### 不会误判的情况

`a*b*c` 和 `2 * 3 = 6` 里的星号**不会被当成斜体**——
只有左侧不是 ASCII 字母数字时，`*` 才算开定界符。

> 这个判断特意**没有**连汉字一起挡：
> `这是*重点*内容` 里的斜体仍然正常渲染。要是按"字母"判断，中文文档的斜体就全废了。

### 转义

想显示字面量的 `*` 或 `` ` ``，前面加反斜杠：`\*`。

## 文档放在哪

文档文件在启动器目录的 `docs` 文件夹里，按语言分成 `zh-CN` 和 `en-US` 两个子文件夹。
想看原始文件、或者用 Typora 之类的编辑器打开，点文档页面右上角的「打开所在文件夹」。

文档会按你当前选择的界面语言自动切换；某种语言的版本缺失时会显示另一种，不会白屏。

---

## 已知限制

- 代码块是等宽字体，**没有彩色语法高亮**
- 不支持图片、脚注、任务列表、HTML 标签
- 表格只支持简单的管道表，不支持单元格内换行与合并
- 行列数不齐时，缺的单元格留空
- 段落里的竖杠 `|` 只有紧跟表格分隔行时才当作表格，普通文字里的竖杠照常显示
